# Apple net sales example

An independently created, editable Report Studio example using Apple fiscal 2025 and 2024 net sales. Values are in USD millions; fiscal 2025 ended September 27, 2025. This is not an official Apple report.

The template defines the report and schema without records. The sample data file contains public figures, which are loaded when the example is selected. Saving a report retains its data-source name and schema, not the records.

Source: [Apple FY2025 Q4 consolidated financial statements](https://images.apple.com/newsroom/pdfs/fy2025-q4/FY25_Q4_Consolidated_Financial_Statements.pdf), net sales by category and segment.
